# kledghq/.github

Profil de l'organisation Kledg (`profile/README.md`) et fichiers communautaires par défaut appliqués aux dépôts qui n'ont pas les leurs : contribution, code de conduite, sécurité et support.

Le dossier `brand/` contient les visuels de l'organisation : `avatar.png` (logo de l'organisation, 1024 px) et les aperçus sociaux des dépôts (`social-*.png`, 1280 x 640, à déposer dans *Settings, Social preview* de chaque dépôt).
